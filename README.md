# Common Ground

Different minds. A world built together.

A cooperative browser game for autistic adults and invited friends, built for Hack the Change 2026. Teams practise everyday conversations, share energy and retrieve components to restore a persistent shared world.

## Current scope

Team Missions first: one greenhouse mission, persistent teams and eight authored adult scenarios. Race and Practice are secondary modes in the design. See the implementation notes as working features land.

- [Eight adult conversations](docs/adult-dialogues.md)

- [AI assistance disclosure](docs/AI-USE.md)

## Development

Node 22.13+ is required. The supplied Vinext/React starter runs on a Cloudflare Worker with D1 persistence. Setup and verification commands will be finalized with the first working slice.

This is a research-informed hackathon prototype, not a validated therapeutic intervention.
