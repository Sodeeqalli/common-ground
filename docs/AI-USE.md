# AI assistance disclosure

OpenAI Codex assisted with research synthesis, concept and rules development, scenario drafting, technical implementation and verification. The team selected the project direction and must review, understand and be able to explain the submitted code and content.

ChatGPT, Google Gemini and Grok were also consulted for concept feedback. The shared-world illustration was generated and simplified using the built-in image-generation tool; its final prompt and use are recorded in [world-art.md](world-art.md). Codex also assisted the pitch, presentation and submission-preparation documents.

The eight authored, deterministic fictional conversations are archived and absent from the shipped gameplay. Players coordinate with each other using signals, requests, pings and optional text chat. No live AI model judges players. Clinical benefit and real-world communication transfer have not been established.

The initial application scaffold uses the OpenAI Sites Vinext starter and its supplied open-source dependencies. Game-specific mechanics, scenarios and interfaces are being created during Hack the Change 2026. Third-party licenses remain with their original code.

Update this record as work progresses and disclose actual AI use in the Devpost submission.
